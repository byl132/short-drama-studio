# 提示词结构与提示词转换

## 一、固定段与变量段

固定段用于连续性，变量段用于镜头变化：

```text
[固定段：角色身份、脸部锚点、体型、服装、道具]
[表演段：情绪、动作、视线、姿态]
[镜头段：景别、机位、焦段感、构图、光线]
[场景段：时间、空间、天气、视角]
[风格段：画面类型、氛围、色彩、镜头语言]
[负面段：缺陷与禁用变化]
```

固定段在同一项目中尽量逐字复用，变量段每次只改变真正需要变化的字段。

## 二、自然语言转结构化字段

把“一个穿旧风衣、看起来很疲惫但很警觉的侦探”转换为：

```text
身份：成年侦探，城市夜班调查者
外形：窄长脸，略深眼窝，短黑发，左眉尾浅疤，偏瘦
服装：深棕旧风衣，灰衬衫，磨损皮鞋
表演：眼神警觉，嘴角克制，肩膀略前倾
变化：允许雨水和衣物褶皱变化；禁止发色、眉尾疤和体型变化
```

“帅、疲惫、有故事”必须继续拆成可看见的五官、姿态、材质、光线或动作；不能把抽象形容词直接当作稳定控制项。

## 三、模型适配

同一资产要保留一个规范化中文字段表，再按模型改写顺序、权重语法、参考图说明和参数。不要把某一模型的权重符号复制到不支持它的模型。

当用户没有指定模型时，输出：

1. 中文规范版：方便人工审阅；
2. 英文/目标模型版：方便复制；
3. 参数表：模型、尺寸、参考图、权重、采样、种子；
4. 负面版：按模型支持情况改为负面提示、排除词或后处理规则。

## 四、镜头提示词示例

```text
固定段：成年侦探，窄长脸，略深眼窝，短黑发，左眉尾浅疤，偏瘦，深棕旧风衣、灰衬衫、磨损皮鞋。
表演段：强忍恐惧，眉心收紧，目光看向画外右侧，右手压住风衣口袋。
镜头段：中近景，略低机位，50mm 电影镜头感，浅景深，人物位于右侧三分之一。
场景段：雨夜旧码头，湿地面反射冷蓝路灯，远处有薄雾。
风格段：写实电影感，克制压迫，冷蓝与少量钨丝暖光对比，细腻皮肤纹理。
负面段：脸部漂移，发型改变，左眉疤消失，头身比异常，额外手指，塑料皮肤，Logo，水印，乱码文字。
```

## 五、每角色的可复用 prompt pack

每个角色必须单独保存：三视图提示词、表情图提示词、全身立绘提示词、场景适配提示词、换装提示词、负面词和“不能改变”清单。不要只保存某一张成图的长提示词。

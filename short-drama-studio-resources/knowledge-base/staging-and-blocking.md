# 场景站位与开场调度（Staging & Blocking）

站位发生在剧本之后、分镜之前。它先固定每个场景「开场时谁在什么位置、朝哪、身边有什么可依靠的物体」，再让分镜复制这些开场句，避免每个镜头重新发明空间。

## 一、输入与输出

| 输入 | 用途 |
|---|---|
| 剧本场次与出场人物 | 必需，决定有哪些角色 |
| 场景卡/场景图 | 提供地点结构、可站立或可坐的物体 |
| 角色卡 | 姓名、体型、服装、随身道具 |
| 道具卡 | 可被依托、可被使用的物体 |

| 输出 | 内容 |
|---|---|
| `staging.json` | 每个场景的开场在场、锚点物体、左右侧、位置、姿态、朝向、群演 |
| `staging.md`（可选） | 盘点表、位置表、开场 blocking 句 |
| 俯视报告（可选） | 可拖拽的平面示意，用于人工复核 |
| blocking 句 | 每场景一句开场调度，直接复制进分镜首段 |

没有场景图时，从场景卡推断的位置标记为 `provisional`，不得当成锁定空间。

## 二、staging.json 字段

```yaml
project_id: PROJECT-001
scene_id: SCENE-001-v01
space_anchors: [门, 窗, 主桌, 吧台]
characters:
  - subject_id: SUBJECT-001-v01
    presence: 在场 / 画外 / 迟到
    anchor_object: 玻璃桌沿
    side: 画左 / 画右 / 中央
    position: 前景 / 中景 / 背景
    posture: 站立 / 坐 / 倚靠 / 蹲
    facing: 面向画右 / 面向对方 / 背对镜头
    props_in_hand: [PROP-001-v01]
extras:
  count: 0
  notes:
status: 待确认 / 已锁定
fidelity: locked / provisional
```

## 三、开场 blocking 句

每场景至少一句，可直接贴入分镜第一镜：

```text
[地点/时间]。江晨站在画右玻璃桌沿，双手撑桌，面向画左；周薄森坐于桌后中景，面向镜头略偏左，右手旁放茶杯。画面无第三人物。
```

规则：

- 用可观察的方位与姿态，不用「气氛紧张」这类不可拍描述；
- 同一场景内角色左右关系与轴线保持一致；
- 锚点物体必须是场景中真实存在的物体；
- 群演数量与位置明确，不临时增加。

## 四、与分镜的交接

- 分镜首段必须复制 blocking 句，不得改写方位；
- 跨场景移动记录 `start → path → end`，中间路径不得穿墙或瞬移；
- 站位锁定后改变方位，视为空间变更，受影响镜头重新 QC 并更新 `continuity-ledger.csv`；
- 站位只管开场与关系，不替代镜头景别、运镜与表演设计。

## 五、验收清单

```text
□ 每个在场角色有左右侧、位置、姿态、朝向
□ 锚点物体存在且可支撑该姿态
□ 轴线与屏幕方向在场景内一致
□ 群演数量明确
□ provisional 项已标注并说明缺失输入
□ 分镜首段已复制 blocking 句
```

# 场景生成、母场景与连续性

本模块把“漂亮背景”变成可重复使用、能容纳人物和道具行动的空间资产。场景的事实来自剧本和用户设定；视觉补充必须标记为 `INFERENCE`、`DESIGN` 或 `ASSUMPTION`。

## 1. 统一 ID 与分流

```text
母场景：SCENE-001-v01
场景变体：SCENE-001-VAR-01
机位扩展：SCENE-001-SHOT-01
```

同一空间在白天、夜晚、雨天或雪天优先建立变体，不重复设计成完全不同的场景。变体必须记录 `variant_of`、保持不变的字段、发生变化的字段、出现场次/镜头和连续性 QC。

已有完整剧本时，先从剧本拆解表和场次—资产矩阵读取空间、人物、道具和动作；只有一句话创意时，先建立最小空间假设并标为 `待确认`。

## 2. 机器可读时间字段

每个母场景和变体分别填写：

| 字段 | 含义 | 不能混淆的内容 |
|---|---|---|
| `world_time` | 世界观年代、历史时期或未来年份 | 不是一天中的拍摄时段 |
| `season` | 季节 | 不是天气本身 |
| `shot_time` | 清晨、白天、黄昏、夜晚等镜头时段 | 不是叙事中经过了多久 |
| `weather` | 晴、雨、雪、雾、风等 | 要写对地面、衣服、能见度和反射的影响 |
| `continuity_time` | 与前后镜头的叙事时间关系 | 例如“紧接上一镜头”“两小时后” |

时间字段改变时，先判断是同一母场景的变体还是新空间；除非剧本明确改变建筑结构，不得借时间变化重构入口、主要动线和关键锚点。

## 3. 场景资产的固定与可变字段

### 固定项

空间骨架、入口/出口、主要通道、人物活动区、关键接触面、关键陈设、主要比例参照、至少 3 个空间识别锚点、建筑/工业/文化时代逻辑。

### 可变项

季节、天气、地面积水/积雪、局部光强、反射、可移动陈设、时间造成的色温和能见度变化，以及剧情明确改变的道具状态。

### 禁止项

不得让不同镜头随意移动入口、楼梯、窗户、轨道、柜台、主通道或关键陈设；不得改变人物可行走路径、道具接触面、空间比例和已锁定的光向逻辑；不得为了“更好看”删掉剧本需要的行动区域。

## 4. 母场景记录

母场景至少写清：

- 空间结构、入口、出口和主要通道；
- 人物活动区域、可行走路径和出入画方向；
- 道具出现位置、可接触面和使用方向；
- 人物与空间的比例参照；
- 主光源、辅光、色温、阴影方向和反射规律；
- 至少 3 个跨景别仍可辨认的空间锚点；
- 与主体、道具、镜头和声音的依赖关系。

空间锚点应是可观察的结构或陈设，例如柱网、窗户排列、轨道/楼梯方向、招牌位置、暖气管线、柜台、门洞或独特地面材质；不能只写“很有城市感”。

## 5. 设计方案与模型候选

先产出 `DESIGN-A/B/C` 三套空间方向，分别说明空间骨架、材质、时代逻辑、光线、动线和制作风险。用户确认方向后，再建立 `MODEL-A/B/C`，三套候选必须保持同一空间骨架、入口、主通道、关键陈设和比例，只比较模型稳定性或适配参数。

不得把三套空间设计方向称作三套模型结果。每套模型记录模型/版本、参数、参考图、生成日期、复用稳定性、视角一致性、文字/Logo 风险和选择理由。

## 6. 生成顺序与最小资产包

### 生成顺序

1. **空间 blockout/全景**：确认骨架、入口出口、动线和锚点；
2. **中景活动区**：确认人物互动位置、尺度、可进入区域和主要道具位置；
3. **近景材质/陈设**：确认接触面、材质、文字和细节；
4. **反向角度**：确认越轴风险、空间闭合和前后镜头衔接；
5. **主体入镜/道具使用测试**：确认脚底接触、比例、阴影、手持关系、景深和光向。

每个核心场景至少保留全景、中景、近景和反向角度记录；需要连续动作时再增加入口、出口和动线测试。

### 场景提示词结构

```text
STYLE_ID 固定段
+ world_time / season / shot_time / weather
+ 空间骨架、入口出口、锚点和人物活动区域
+ 道具位置与接触面
+ 视角、景别、机位和镜头变量
+ 负面段
```

场景提示词应说明“空间关系”和“可执行动作”，而不是只堆形容词。变体提示词只替换允许变化的字段，并显式写出 `variant_of`。

## 7. 场景验收矩阵

| 检查项 | 验收问题 | 不通过时的回退 |
|---|---|---|
| 空间骨架 | 全景能否看出入口、出口、通道和主要区域？ | 回到母场景 blockout |
| 锚点 | 至少 3 个锚点在不同景别/角度仍可识别？ | 补锚点或重建母场景 |
| 动线 | 人物能按剧本进入、行动、互动和离开？ | 改空间比例或活动区，不改人物事实 |
| 比例 | 主体、道具、门窗、台阶和接触面尺度自然？ | 用入镜图/使用图校正 |
| 光影 | 主光方向、接触阴影、反射和色温连续？ | 回退到场景光照设定 |
| 变体 | 时间/天气改变但骨架、锚点和动线未漂移？ | 只修变体字段 |
| 视角 | 全景、中景、近景、反向角度可互相剪接？ | 修机位或重做反向角度 |
| 时代与授权 | 时代、文化细节、招牌/Logo来源可解释？ | 改为虚构或暂停生成 |

## 8. 交接给道具、主体和镜头模块

交接至少包括：`SCENE_ID`、母场景/变体关系、五个时间字段、空间锚点、入口出口、人物动线、道具位置、比例/阴影 QC、场景提示词和负面词、模型候选、来源/授权日志、已锁定字段和未决问题。镜头只能在这些字段允许的范围内改变景别、构图、动作和局部光线。

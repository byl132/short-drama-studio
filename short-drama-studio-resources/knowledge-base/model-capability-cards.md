# 模型能力卡与按能力选模型

模型名称、版本、价格、时长上限和接口都会变化。本文件只记录**能力假设**，不构成对任何平台当前限制的承诺。提交前必须以目标平台当次官方文档复核；能力冲突时以实际接口为准，不以品牌印象排名。

## 一、选型原则

1. 先写清任务需要的输入输出，再选模型：文生视频、图生视频、参考图/参考视频生视频、首尾帧、音频/声线参考、编辑续写、多镜合生。
2. 用「主模型 + 备份模型 + 快速预览模型」三层，一个镜头不随机换模型。
3. 同一资产尽量固定主模型与版本；换模型必须重新做连续性测试，不能直接拼接。
4. 每个生成请求记录：模型/版本、模式、参考资产 ID、提示词版本、参数、种子、费用、日期、授权和选片理由。

## 二、五镜测试法

用五个测试镜头评估候选模型，每项 1–5 分：

| 测试镜头 | 观察重点 |
|---|---|
| 人物近景 | 脸部锚点、发型、肤色、眼神稳定 |
| 走路全身 | 步态、重心、关节、脚底接触 |
| 手与道具互动 | 手指数量、握持姿态、道具形变 |
| 双人对话 | 嘴型主体、非说话者闭嘴、视线与轴线 |
| 镜头运动 | 推拉摇移的稳定性、透视变化、背景重绘 |

评分维度：身份稳定、动作自然、空间连续、画质、生成速度、成本、修复难度。总分接近时，优先可复现、可批量、授权与导出链路清楚的模型。

## 三、能力卡（起始假设）

> 下列分组按**能力**归类，不代表具体版本参数。

### CARD-T2V 文生视频

- 适用：氛围、环境、动作方向探索，无锁定角色资产。
- 风险：人物与空间连续性弱。
- 验收：先看构图与运动方向，再决定是否升级为图生视频。

### CARD-I2V 图生视频

- 适用：已有角色三视图、表情图、场景图，需要锁定角色、服装、道具。
- 风险：脸部漂移、手部异常、口型不准。
- 验收：首帧必须来自已锁定资产，参考图干净无水印。

### CARD-R2V 参考驱动

- 适用：同一角色跨镜头、风格迁移、动作修正。
- 风险：运动残影、画面被过度重绘、参考权重过高导致僵硬。
- 验收：多角色时逐一绑定参考，检查是否串脸。

### CARD-FL 首尾帧

- 适用：需要精确起止状态的镜头、转场桥接、动作闭环。
- 风险：中段插值失真、物理不合理。
- 验收：逐帧检查接触点与方向，不只看首尾两张。

### CARD-AUDIO 音频/声线参考

- 适用：原生对白、声线绑定、口型驱动、配乐。
- 风险：串声、错人开口、非说话者同步嘴型。
- 验收：转写核对说话人，静音也能看懂剧情。

### CARD-EDIT 编辑/续写/修复

- 适用：局部缺陷修复、镜头延长、接缝桥接。
- 风险：编辑区域边缘跳变、整体风格漂移。
- 验收：对比编辑前后，检查接缝处光向与材质。

### CARD-MULTI 多镜合生

- 适用：一次生成多个有内在切镜的短段。
- 风险：内部切镜负载过重、后半段漂移。
- 验收：先验收子镜头负载与内部切镜点，再入片。

### CARD-IMG 高保真图像/编辑

- 适用：角色/场景/道具母版、覆盖方案、冻结关键帧、局部改图。
- 风险：文字与 Logo 失控、多姿势拼版复制成额外角色。
- 验收：同一 `asset_id` 跨视角稳定；精确文字另建 `text_plate_id` 后期合成。

## 四、能力卡模板

新建模型卡时复制以下字段：

```yaml
card_id: CARD-xxx
model_family:
capabilities: [T2V|I2V|R2V|FL|AUDIO|EDIT|MULTI|IMG]
input_contract: 图像/视频/音频/文本/参考数量
output_contract: 时长/分辨率/帧率/透明通道
duration_range: 待核实
resolution_range: 待核实
strengths:
known_risks:
acceptance_checks:
evidence_level: 文档能力 / 实测结果 / 创作偏好 / 推断
verified_at: YYYY-MM-DD
source_url:
```

## 五、交接

选定模型后，把 `card_id`、版本、参数与测试记录写入 `templates/video-production-spec.md` 和 `templates/generation-jobs.csv`；模型变化时按 `knowledge-base/generation-operations.md` 让下游确认失效。

# 生产流程与资产模型

## 一、资产优先

短剧画面由可复用资产组成：角色、道具、风格、场景、镜头。每个资产都要有“固定字段”和“可变字段”。固定字段保证连续性，可变字段服务剧情。

统一顺序：

1. `STYLE`：先锁定画面类别、材质、色彩、光线和镜头语言；
2. `SUBJECT`：再锁定人物/动物/幻想主体的身份、外形、表演和变体；
3. `SCENE`：建立母场景、空间锚点、时间字段和场景变体；
4. `PROP`：制作道具/产品母体、多状态和使用关系；
5. `SHOT`：最后把已锁定资产组合进镜头。

已有完整剧本时，先执行剧本拆解和资产总表，再进入这条资产顺序。课程编号不覆盖项目交接协议。

## 二、提示词四维结构

```text
光影/时间 + 主体 + 场景 + 风格
```

### 光影/时间

用可拍摄的时间描述光线：清晨侧逆光、正午硬顶光、雨夜冷色路灯、黄昏暖色低角度光。必要时加季节、年代和能影响服装/材质的环境条件。

### 主体

先写主体，再写动作和状态。人物主体应引用角色固定段，不在每个镜头重新发明脸部细节。

### 场景

场景由四项构成：

- 时间：年代、季节、具体时段；
- 空间：建筑结构、入口/出口、道具位置、可行走路径；
- 天气：晴、雨、雪、雾、风，以及它如何影响衣服、地面和能见度；
- 视角：全景建立关系，中景呈现互动，近景承载情绪。

### 风格

用四个控制项锁定风格：

- 画面类型：写实、动画、电影、广告、纪实、二维/三维等；
- 氛围参考：温暖、压迫、神秘、浪漫、荒诞；使用可观察的光色、材质和构图，不直接点名在世创作者；
- 色调/光源：冷暖、饱和度、对比度、主光/辅光/轮廓光、逆光或轮廓光；
- 镜头语言：景别、角度、焦段感、景深、焦点转移、稳定或手持。

风格的两种工作模式、参考作品转译、`DESIGN/MODEL` 分离和风格测试见 [style-system.md](style-system.md)。

## 三、资产表建议字段

### 角色

```text
角色 ID / 识别句 / 年龄段 / 身份 / 时代与地域
脸型 / 眼眉 / 鼻口 / 发型 / 肤色 / 特殊标记
身高体型 / 服装 / 鞋 / 配件 / 随身道具
表演习惯 / 允许变化 / 禁止变化 / 参考图及授权
```

### 道具

```text
道具 ID / 形状 / 尺寸 / 材质 / 主色 / 磨损
使用动作 / 出场镜头 / 可见面 / 连续性规则 / 来源授权
```

### 场景

```text
场景 ID / 时间 / 季节 / 空间结构 / 出入口 / 天气
主光源 / 色温 / 机位候选 / 景别候选 / 连续性锚点
```

母场景、场景变体、`world_time`、`season`、`shot_time`、`weather`、`continuity_time` 以及全景/中景/近景/反向角度验收见 [scene-generation.md](scene-generation.md)。

```text
提示词：固定段 + 变量段 + 镜头段
负面词：
```

## 五、质量顺序

先检查故事可读性和空间连续性，再检查角色身份，最后检查纹理与审美。不要用“画面很漂亮”替代角色和叙事的验收。

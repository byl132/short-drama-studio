# 生成运营：门禁、幂等、费用与证据边界

本模块约束「什么时候可以生成、失败如何恢复、花了多少钱、什么算证据」。它与 `templates/generation-jobs.csv`、`templates/candidate-scorecard.csv` 配合使用。

## 一、门禁式生成顺序

1. 验收故事与剧情段计划；
2. 验收人物、风格、世界与道具母版；
3. 先生成钩子段或最高风险段，不从头批量铺；
4. 下载并直接检查真实输出，不凭提示词想象结果；
5. 15–30 秒段制作 12 帧接触表，至少看开头、25%、50%、75%、结尾；
6. 慢放检查接触峰值、穿模与物理；
7. 有音频时转写并人工听；
8. 用证据标记 `accepted / repair / rejected`；
9. 提取验收尾帧，更新 `continuity-ledger.csv`；
10. 之后才解锁依赖段。

可并行：独立母版、音乐探索、声线、非依赖插镜、备选钩子。不可并行：尚未获得已验收父状态的连续剧情段。

## 二、幂等与中断恢复

每个生成请求写入 `templates/generation-jobs.csv`：

```text
job_id, request_fingerprint, idempotency_key, block_id, model, model_version,
mode, input_refs, prompt_version, params, status, attempt,
cost_estimate, output_file, parent_job, accepted_tail, created_at, updated_at, notes
```

- `request_fingerprint`：模型 + 版本 + 提示词版本 + 参考资产 + 参数 + 尺寸/时长的哈希；
- `idempotency_key`：同一逻辑请求复用同一键，防止重复扣费；
- 超时先标记 `unknown`，查询后再决定，不把未知当失败盲目重提；
- 人工修改上游状态后，使受影响的确认与下游任务失效；
- 已创建任务先查询状态，再决定重提或续跑。

## 三、费用与授权分档

质量档（描述投入，不等于付费许可）：

| 档位 | 用途 |
|---|---|
| Sketch | 最低可用预演 |
| Economy | 720p、长段优先、定点修复 |
| Balanced | 把强参考/音频模型用在真正提高通过率的段 |
| Premium | 富多模态、参考音频、编辑续写、选择性高清 |
| Hero Insert | 集中预算做钩子、高潮、复杂接触、情绪特写 |
| Final Polish | 只放大和修复已验收素材 |

授权档（决定能不能花钱）：

```text
plan-only     只出计划，不提交
single-test   单条测试，需明确确认
approved-batch 已确认范围与费用的批量
autopilot-with-cap 预授权，但有费用与重试上限
```

用户已预先授权平台、上传规则、预算与重试上限时，不逐条重复询问；触及边界必须停止并确认。

## 四、候选评分

多个候选先过 MUST-HIT 二元门（身份、方向、嘴型主体、关键道具），再用 `templates/candidate-scorecard.csv` 比较：剧情、身份、空间、物理、表演、声音、可剪辑性。

- 关键候选尽量盲化模型、种子、费用与生成顺序；
- 评审者先发现和分级问题，创作/修复者再决定改法；
- 不把单张最惊艳的结果直接当主版本。

## 五、证据边界

项目文档必须区分四类信息：

| 类型 | 含义 |
|---|---|
| 文档能力 | 从当前正式参数页或接口结构核实 |
| 实测结果 | 特定模型、入口、日期与配置下观察到 |
| 创作偏好 | 为当前故事主动选择 |
| 推断 | 有可能但未经直接验证 |

不得把动态价格、时长上限或模型质量写成永恒事实。没有实际调用时写「待生成」，不伪造结果。

## 六、按任务范围交付

不要把完整制作包强加给局部请求，只创建下一步确实会读取或验证的文件：

- 诊断/建议：问题证据、优先级、最小修复；不生成空白 CSV。
- 故事/剧本：生产简报、剧情合同、剧本/节拍；连续性确有需要时才建母版。
- 分镜/生产包：覆盖方案、生成段、剪辑节拍、参考权威、模型能力卡、费用与声音路线。
- 执行：请求预览与指纹、幂等键、任务/恢复记录、候选谱系、费用账本、真实输出、QA 证据、尾帧。
- 成片/发布：带来源链的时间线、媒体标准化、混音、字幕、封面、编码与冷观众报告。

## 七、命名与密钥

- 统一命名：`BLOCK_ID_vN.mp4`、`BLOCK_ID_vN_tail.png`、`BLOCK_ID_vN_contact_12.jpg`、`BLOCK_ID_vN_audio.wav`、`BLOCK_ID_vN_QA.md`。
- 密钥只能来自环境变量或用户本地 secrets 文件，不得写进项目、日志或仓库。

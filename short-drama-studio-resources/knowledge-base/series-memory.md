# 系列记忆与长篇改编

长篇、连续剧或跨集 IP 的最大风险不是「写不出来」，而是上下文丢失、设定冲突和伏笔遗忘。本模块用分层事实代替「把全文反复塞进提示词」。

## 一、四层记忆

| 层 | 内容 | 变更频率 |
|---|---|---|
| 世界事实 | 地点、规则、时间线、势力关系 | 低，但需版本化 |
| 人物知识 | 每个角色「知道什么、不知道什么、何时得知」 | 中 |
| 叙事时间线 | 事件顺序、因果、倒叙与揭示位置 | 中 |
| 揭示状态 | 哪些信息已对观众/角色公开 | 高 |

提示词只引用当前镜头需要的事实层，不复制全文，也不依赖对话历史记忆。

## 二、原著抽样快评

拿到长原著时，不立即整本拆解：

1. 抽样首章、转折章、高潮章、结尾章；
2. 输出题材、核心矛盾、主角弧光、可拍性、改编风险；
3. 给出「值得整本拆解 / 只取局部 / 不建议改编」的判断；
4. 用户确认后再做章节索引与逐章梳理。

## 三、章节索引

```text
章节号 | 篇幅 | 地点 | 出场人物 | 关键事件 | 新增设定 | 伏笔/回收 | 可拍性评分
```

索引用于分集切割，不替代剧本拆解。

## 四、伏笔台账

| 伏笔 ID | 埋设位置 | 内容 | 回收位置 | 状态 |
|---|---|---|---|---|
| FORESHADOW-001 | EP01-SC03 |  |  | 待回收 / 已回收 / 弃用 |

伏笔必须有回收计划或明确弃用说明，不能写了就忘。

## 五、跨集连续性

- 角色外观、服装、道具状态变化写入 `continuity-ledger.csv`，标注所属集数；
- 人物知识状态变化（例如「她知道了真相」）必须记录发生集与镜头；
- 时间跳跃、回忆、平行线在叙事时间线中显式标注；
- 剧本修改后做 SCRIPT DIFF，保留旧版本，受影响资产重新 QC。

## 六、分集与批量

- 默认每批处理 1–3 集，先做一集样片再扩展；
- 每集先声明时长、钩子、结尾动作，再写节拍；
- 跨集钩子不要用泛泛的「未完待续」，要留下具体问题、倒计时或关系变化；
- 静态漫剧可从首帧图与配音直接进入生产与剪辑，不强制走完整视频流程。

## 七、验收清单

```text
□ 世界事实与人物知识分层记录
□ 每个伏笔有回收或弃用说明
□ 时间跳跃与回忆已标注
□ 角色知识状态与揭示位置可追溯
□ 剧本变更已做 SCRIPT DIFF
□ 受影响资产与镜头已重新 QC
```

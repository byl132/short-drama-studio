# 物理门与连续性账本

画面意图正确但物理方向错误，仍判失败。本模块在视频生成前约束接触、支撑、方向与状态，并用连续性账本记录正式状态。

## 一、生成前：接触点清单

逐镜头列出可见 `physical_contact_points`：

```text
手/脚/爪 → 物体/地面/水面/他人
工具 → 握持点、施力方向
布料 → 悬垂、褶皱、遮挡
液体 → 容器、飞溅、表面张力
车辆 → 轮胎接地、转向、惯性
动物 → 四肢着地、尾巴、负载
魔法/特效 → 起点、路径、衰减、终态
```

不同主体的接触规则不同，不得用同一套动作原语硬套。

## 二、动作原语顺序

统一顺序：`接近 → 接触 → 施力 → 响应 → 稳定结果`。

提示词写清起点、动作、终点，例如「角色伸手 → 握住杯柄 → 提起 → 水面晃动 → 杯底离桌停稳」，不要只写「自然地拿起杯子」。

## 三、精确物理事件编译

倒车、转向、脱落、碰撞、抛接、开门必须编译成：

```text
physical_start_state → control_input → world/screen motion vectors
→ phase_sequence → physical_end_state
```

规则：

- 一个生成段只承担一个高风险精确物理事件；
- 复杂事件拆成「建立 / 峰值 / 后果」三个镜头；
- 意图正确但方向错误仍判失败；
- 一镜内最多改变一到两个重点变量（动作/表情/机位/光线/天气）。

## 四、必须拒绝的失败

```text
身体或物体穿透
额外或缺失的肢体/手指/动物
不可能支撑（悬空、反重力）
道具瞬移或无解释复位
手机/标志/文字方向反转
服装结构改变（口袋、扣子、领口漂移）
因果不可见（结果发生了，但看不到原因）
```

## 五、空间与遮挡

- 多角色调度先锁地点锚点与连通关系，再写 `start → path → end`。
- 镜面、巨物、设施、复杂出入口先写反射拓扑、尺度关系与遮挡顺序。
- 提示词不得临时发明位置或连通关系。

## 六、连续性账本

用 `templates/continuity-ledger.csv` 维护正式状态，每个验收段都更新。字段：

```text
asset_id, scene_id, shot_id, state_id, prop_id, variant_of,
screen_direction, light_direction, costume_state, prop_state,
continuity_time, notes, updated_at
```

规则：

- 资产通过稳定 ID 引用，不复制大段正文；
- 状态变化（变老、受伤、换装、淋湿、破损）建立 `variant_of`，记录不变字段与允许变化字段；
- 镜头间只改变账本中已声明的变量；
- 上游状态改变后，受影响的下游资产与镜头必须重新 QC。

## 七、接触表验收

对 15–30 秒段制作 12 帧接触表，至少检查：开头、25%、50%、75%、结尾。

- 慢放检查接触峰值、穿模、手指、支撑点；
- 有音频时转写并人工听；
- 用证据标记 `accepted / repair / rejected`；
- 只有 `accepted` 的尾帧可以更新连续性账本并解锁下游段。

# 对白、声线与声音路线

声音不是画面完成后的补丁。对白路线决定镜头怎么拍、口型怎么保护、后期怎么分轨。先在 `templates/video-production-spec.md` 声明声音路线，再进入视频生成。

## 一、五条声音路线

按场景选择，不要求整片统一：

| 路线 | 适用 | 关键约束 |
|---|---|---|
| 无对白 | 氛围、动作、纯视觉叙事 | 统一环境底、音乐结构、精选拟音 |
| 原生对白 | 台词短、说话人明确、说话时有动作 | 说话人可见开口；之后留反应 |
| 参考音频 | 常驻角色需要稳定声线 | 每个说话人一条授权声线锚点 |
| 外部配音 | 口型工具或 TTS 后期 | 用反应、侧脸、远景、插镜、画外音保护可信度 |
| 混合 | 保留好的原生英雄台词 | 旁白/电话/环境/音乐后期统一 |

## 二、声线锚点

每个常驻说话人建立独立声线锚点，锁定：语言、口音、语速、音色、强度、情绪范围、授权状态。

- 声线锚点必须来自授权素材或自建声音；免费或来源未授权的音色只能登记为 `evaluation-only`，不得进入商业成片。
- 声音克隆需要明确授权与使用范围；未成年人声音默认不处理。
- 声线锚点与角色 ID 绑定，换配音演员视为新变体 `SUBJECT-001-VAR-VOICE-01`。

## 三、多人对白规则

每句对白记录：

```text
speaker_id / 可见或画外声源 / 镜头中的嘴型主体 / 非说话者嘴部状态 / 轮次 / 停顿
```

- 说话时必须由该角色本人可见开口，或明确使用有来源的广播/画外音。
- 其他角色保持闭嘴，只做倾听与反应。
- **错人开口、声音串角色、非说话者同步嘴型属于 P0 缺陷**，不得用字幕掩盖，必须重生成或改配音。

## 四、分轨与剪辑

- 对白、旁白、环境声、拟音、音乐、音效分别保存，不提前混成一轨。
- 统一 48 kHz 时间线；保留 24-bit WAV 分轨。
- 连续场景跨镜头保持房间底噪/雨声连续；用 J cut / L cut 过渡，不让每次切画面都重启声音。
- 音乐避让对白（ducking），关键台词前后留呼吸和反应。
- 默认硬切优先；承接用声音桥，而不是用音乐掩盖剧情失败。

## 五、响度与字幕

- 网页成片可从约 -16 LUFS integrated、true peak 低于 -1 dBTP 作为起始目标，按平台或广播标准复核。
- 字幕与配音同步；一条字幕最多两行，按语义断句。
- 中文阅读速度可从每秒约 12–16 个汉字作为起始参考，最短显示约 1 秒。

## 六、口型不稳的保护

AI 原生口型不稳定时，按优先级处理：

1. 拆短句，一句一个主要信息；
2. 用反应镜头、侧脸、远景、插镜、画外音承接；
3. 后期配音并重新对齐口型；
4. 仍不可控时改台词或改成无对白表演，不用字幕解释嘴型错误。

## 七、验收清单

```text
□ 每个说话人有 speaker_id 与声线锚点（或明确无对白）
□ 无错人开口、串声、非说话者同步嘴型
□ 对白/音乐/环境分轨保存
□ 响度达标，无削波、爆音、明显底噪
□ 字幕与配音同步，安全区内显示
□ 声音、克隆与音乐授权已登记
```

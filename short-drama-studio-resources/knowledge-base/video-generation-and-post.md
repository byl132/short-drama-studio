# AI 视频生成与后期剪辑规范

## 一、先定义交付，再选择模型

在生成第一条视频前填写 [templates/video-production-spec.md](../templates/video-production-spec.md)，锁定时间线、画幅、帧率、色彩、音频、字幕和导出平台。模型名称、版本和能力会变化，以下规则优先于品牌名称；使用时必须以当前工具的实际输入限制和平台上传规则为准。

## 二、AI 视频模型选择

| 任务 | 首选模式 | 适合内容 | 主要风险 |
|---|---|---|---|
| 快速探索环境、气氛、动作方向 | 文生视频 | 无明确角色资产的氛围镜头、概念预演 | 人物和空间连续性弱 |
| 锁定角色、服装、道具 | 图生视频 | 已有角色三视图、表情图、场景图 | 脸部漂移、手部和口型异常 |
| 延续上一镜头或改造现有素材 | 参考图/参考视频生视频 | 同一角色跨镜头、风格迁移、修正动作 | 运动残影、画面被过度重绘 |
| 复杂走位、稳定相机和物理关系 | 3D 场景/动作驱动 | 多人调度、重复机位、产品或道具特写 | 建模、绑定和渲染成本高 |
| 平面角色、分层动画、口型与表情 | 2D 绑定/逐帧/图生视频 | 插画、漫画、UI 合成、二维短剧 | 图层边缘、插值和形变穿帮 |

模型选择用“主模型 + 备份模型 + 快速预览模型”三层，而不是每个镜头随机换模型。用五个测试镜头评估：人物近景、走路、手与道具互动、双人对话、镜头运动；每项按 1–5 分记录身份稳定、动作自然、空间连续、画质、生成速度、成本和修复难度。总分相近时优先选择可复现、可批量、授权和导出链路清楚的模型。

每次生成记录：模型/版本、模式、参考图 ID、提示词固定段、动作段、负面词、尺寸、帧率、时长、种子或随机参数、生成日期、授权状态和选片理由。没有实际调用工具时，明确标注“待生成”，不伪造生成结果。

## 三、镜头生成单位

- 一条 AI 视频只承担一个主要动作、一个镜头目的或一次情绪变化；不要直接生成整集；
- 先用短片段验证动作和构图，再扩展时长或生成变体；建议单镜头从 2–8 秒起步，具体上限以模型为准；
- 人物镜头优先使用角色 ID、正面/侧面参考图和明确的起止姿态；
- 运动提示词写“起点—动作—终点”，例如“角色抬头，看向画外右侧，停顿，缓慢后退”，不要只写“自然运动”；
- 一个镜头只改变少数变量：动作、表情、机位、光线、天气中最多选择一到两个重点；
- 先生成无字幕、无 Logo、无音乐的干净画面，文字和声音在后期统一加入。

## 四、镜头衔接规范

默认使用硬切，转场必须有叙事或声音动机：

| 衔接方式 | 使用场景 | 检查点 |
|---|---|---|
| 动作切 | 同一动作跨镜头完成 | 动作方向、速度和身体位置连续 |
| 视线切 | 角色看向画外后切到被看对象 | 视线方向和屏幕轴线一致 |
| 匹配剪辑 | 形状、动作、构图或声音相似 | 前后镜头的视觉元素有明确匹配 |
| 声音桥 | 先听到下一场景的声音再切画面 | 声音提前/延后有明确意图 |
| 反应切 | 重点从说话者切到听者 | 给反应留足 1–3 秒，不只拍说话嘴型 |
| 叠化/淡入淡出 | 时间跳跃、回忆、段落结束 | 不用于掩盖 AI 画面穿帮 |
| 推拉/遮挡转场 | 门、人物、暗部或运动物体遮挡切换 | 遮挡方向、光线和速度连续 |

避免在每个镜头使用炫技转场。若 AI 片段出现脸部融化、手指突变、背景跳动或物理错误，优先用硬切、插入镜头、反应镜头、定格或声音桥绕开；不要用强烈转场把错误藏起来。

## 五、后期剪辑顺序

```text
备份原始素材与元数据
→ 建立项目/代理文件和时间线
→ 同步对白与参考音
→ 粗剪：先保证故事和节奏
→ 精剪：动作切、视线、轴线、反应和连续性
→ 声音：对白、环境、拟音、音乐、静音
→ 调色/合成：统一 2D、3D、AI 与实拍的光色和颗粒
→ 字幕/标题/版权标识
→ 母版导出 → 平台版本导出 → 全片 QC → 归档
```

剪辑中保留未裁切原片、项目文件、代理文件、音频分轨、字幕文件、字体、参考图、模型参数、提示词和授权记录。不要反复把平台压缩版下载再压缩。

## 六、音效、对白和字幕

### 音频

- 项目时间线和交付音频统一使用 48 kHz；保留 24-bit WAV 分轨；
- 分开保存对白、旁白、环境声、拟音、音乐和音效，不把所有声音过早混成一轨；
- 对白优先可懂度，关键台词前后留反应和呼吸；AI 口型不稳时采用后期配音并重新对齐口型镜头；
- 网页成片可从约 -16 LUFS integrated、true peak 低于 -1 dBTP 作为起始目标，音乐和音效服从对白；不同平台或广播标准不一致时按目标标准复核；
- 生成音乐、音效和声音克隆同样要记录来源、授权和商业使用范围。

### 字幕

- 同时输出可编辑的 SRT/VTT 和烧录版字幕；
- 一条字幕最多两行，单行尽量短，按语义断句，不把人名、时间码和动作说明挤在对白里；
- 中文阅读速度可从每秒约 12–16 个汉字作为起始参考，最短显示约 1 秒，长句按停顿拆分；
- 字幕放在平台安全区内，保证与底部按钮、头像、标题和进度条不重叠；
- 关键音效、旁白、说话人变化按项目需求标注；
- 字体、字号、描边、阴影、颜色和位置在全季统一，避免使用未授权字体。

## 七、2D、3D 与 AI 视频输入/输出

### 2D 输入

```text
角色/背景：PNG、PSD、SVG 或分层图；每层独立命名，保留透明通道
动画：逐帧 PNG 序列、分层工程文件或带透明通道的中间格式
色彩：明确 sRGB/Rec.709；需要调色时保留高位深源文件
画幅：按目标比例制作，常用 1920×1080、1080×1920、1080×1350、1080×1080
```

### 3D 输入

```text
模型：glTF/GLB、FBX、OBJ 或项目引擎格式；记录单位、轴向和版本
材质：PBR 的 base color、roughness、metallic、normal、opacity 分开管理
动画：骨骼、绑定、blendshape/表情、动作起止帧和帧率明确
镜头：焦距、传感器/视场角、机位、目标点和景深参数明确
灯光：主光、辅光、轮廓光、HDRI、色温、阴影和渲染色彩空间明确
```

不同软件的轴向、单位、色彩管理和材质命名可能不同，导入前写转换规则，不默认“打开就一致”。

### 2D/3D 输出

- 需要透明通道或继续合成：优先 PNG/EXR 序列或支持 Alpha 的中间格式；
- 2D 合成可交付 RGBA PNG 序列，3D/特效合成优先线性工作流的高位深 EXR；
- 最终平台视频通常不保留 Alpha，使用不带透明通道的 H.264/H.265 MP4 或平台接受的中间格式；
- 输出前确保画幅、帧率、色彩空间、像素宽高比、运动模糊、景深和音画同步一致。

### AI 视频输入

参考图要干净、清晰、无水印/Logo、比例接近目标画面，长边建议至少达到模型要求的清晰度；提交前确认参考图和真人素材授权。图生视频优先使用锁定后的角色资产和场景资产，不用聊天截图、压缩严重的二次平台图或多张互相矛盾的参考图。

## 八、母版与主流平台输出

平台规格会调整，以下是便于制作的推荐档案，不是对平台当前限制的承诺；上传前以目标平台的最新要求复核。

| 用途/平台类型 | 画幅与推荐尺寸 | 帧率 | 推荐视频 | 推荐音频 |
|---|---|---|---|---|
| 抖音、TikTok、Instagram Reels、YouTube Shorts | 9:16，1080×1920 | 24/25/30 fps，按时间线保持一致 | MP4，H.264 High，VBR 约 8–20 Mbps | AAC-LC，48 kHz，192–320 kbps |
| 小红书竖版内容 | 3:4 1080×1440 或 4:5 1080×1350；需要全屏时 9:16 | 24/25/30 fps | MP4，H.264，VBR 约 8–20 Mbps | AAC-LC，48 kHz |
| 哔哩哔哩/网页横版 | 16:9，1920×1080 | 24/25/30 fps | MP4，H.264 High，VBR 约 10–25 Mbps | AAC-LC，48 kHz，192–320 kbps |
| 微信视频号/社交横竖双版 | 9:16 1080×1920 或 16:9 1920×1080 | 与母版一致 | 分别导出，不强行在一个文件内兼容两种构图 | AAC-LC，48 kHz |
| 正方形信息流 | 1:1，1080×1080 | 24/25/30 fps | MP4，H.264，VBR 约 8–15 Mbps | AAC-LC，48 kHz |

## 九、导出层级

1. **归档母版**：保留原始帧率和分辨率；优先 ProRes 422 HQ/4444、DNxHR HQX 或同级中间格式；有透明通道时使用支持 Alpha 的格式；
2. **平台母版**：按平台画幅导出 H.264/H.265 MP4，保持原时间线帧率，避免不必要的二次缩放；
3. **字幕版本**：无字幕干净版、烧录字幕版、外挂 SRT/VTT 版；
4. **音频版本**：完整混音版、无音乐版、对白/旁白分轨版（按项目需要）；
5. **封面与预览**：按平台单独制作安全构图，不从有字幕或 Logo 的视频帧随意截取。

## 十、成片 QC

```text
画面：无黑帧、卡帧、闪烁、重复帧、AI 融化、穿帮、画幅拉伸和错误裁切
连续性：人物脸、服装、道具、轴线、光向、天气、时间和运动方向一致
声音：对白清楚，无削波、爆音、明显底噪和音乐盖词；音画同步
字幕：无错别字、漏字、乱码、超安全区、闪现过快和遮挡主体
导出：分辨率、帧率、编码、码率、色彩、音频采样率和时长符合交付档案
合规：参考图、字体、音乐、音效、声音克隆、Logo 和 AI 合成标识均有记录
```
